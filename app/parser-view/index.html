Thrift 转 JSON Schema 在线转换器

编辑 Apache Thrift 定义，生成 JSON Schema，再用样例数据验证字段约束。

转换示例

struct User { 1: required string name }

生成的 Schema 要求对象包含字符串字段 name。

{"type":"object","properties":{"name":{"type":"string"}},"required":["name"]}

SDK 用法

pnpm add @trasm/thrift-jsma
import { parseThriftToJsonSchema } from '@trasm/thrift-jsma'
const schema = parseThriftToJsonSchema('struct User { 1: required string name }')
